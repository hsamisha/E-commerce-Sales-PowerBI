# E-Commerce Sales Data Analysis Using Power BI


## Project Overview

The E-Commerce Sales Data Analysis project focuses on analyzing sales transaction data using Microsoft Power BI. The project aims to understand business performance, product demand, customer purchasing patterns, and sales trends through interactive dashboards and visualizations. Power BI is used to transform raw data into meaningful insights that support data-driven decision-making.

## Objective

The main objective of this project is to analyze e-commerce sales data and develop an interactive Power BI dashboard to monitor business performance.

The key objectives are:

- Analyze total sales, order counts, and quantity sold.
- Identify top-performing products and categories.
- Understand monthly sales trends and geographical sales distribution.
- Compare sales performance across customer types and sales channels.
- Present key performance indicators (KPIs) through an interactive dashboard.

## Dataset Description

The dataset contains e-commerce sales transaction details, including order information, product details, quantities, sales amounts, locations, and other relevant business attributes. The data is used to analyze sales performance, product demand, order patterns, and geographical distribution.

## Tools and Technologies Used

- **Microsoft Power BI Desktop:** Used to create interactive dashboards and reports.
- **Power Query Editor:** Used for data cleaning and transformation.
- **DAX (Data Analysis Expressions):** Used to calculate KPIs and create measures.
- **Data Modeling:** Used to organize data and establish relationships where required.
- **Data Visualization:** Used to present insights through charts, graphs, cards, and slicers.

## Approach and Methodology

The project follows a structured data analysis workflow:

1. **Data Loading:** Imported the e-commerce dataset into Power BI.
2. **Data Cleaning:** Handled missing values, duplicates, and data type inconsistencies using Power Query.
3. **Data Transformation:** Prepared and organized the data for analysis.
4. **KPI Creation:** Developed measures for total sales, unique orders, quantity sold, and average order value.
5. **Data Modeling:** Organized the dataset and established appropriate relationships where needed.
6. **Dashboard Development:** Created visualizations to analyze sales, products, time trends, and geographical performance.
7. **Insights Generation:** Interpreted dashboard results to identify business trends and opportunities.

## Analysis and Key Findings

The Power BI dashboard covers the following areas:

- **Sales Performance:** Analyzes total sales and average order value.
- **Order Analysis:** Tracks order counts and purchasing patterns.
- **Product Analysis:** Highlights products with strong sales performance.
- **Monthly Sales Trends:** Examines changes in sales over time.
- **Geographical Analysis:** Compares sales across states and locations.
- **Customer and Channel Analysis:** Evaluates sales across available customer types and sales channels.

The dashboard helps users explore business performance through interactive visuals and filters.

## Key Insights

The dashboard provides an overview of sales performance, product demand, order patterns, and geographical differences. KPI cards summarize important metrics, while charts help identify trends, compare product performance, and explore sales variations across different locations and periods.

## Recommendations

- Focus on high-performing products to improve sales opportunities.
- Monitor monthly sales trends for better planning and forecasting.
- Investigate lower-performing locations to identify potential growth opportunities.
- Track KPIs regularly to evaluate business performance.
- Use customer and sales channel analysis to improve marketing strategies.
- Maintain accurate and updated data for reliable reporting.

## Conclusion

The E-Commerce Sales Data Analysis project demonstrates how Microsoft Power BI can be used to transform raw sales data into an interactive and informative dashboard. Through data cleaning, transformation, DAX calculations, and visualizations, the project helps users understand business performance and identify opportunities for improvement.

The dashboard supports data-driven decision-making by presenting key metrics and sales trends in a clear and accessible format.
